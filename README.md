# Hotel Shyadri - Digital Guest Portal & In-Room Services

An interactive in-room dining, toiletries request, and guest services portal for Hotel Shyadri.

## Features
- **In-Room Food & Drink Ordering** with quantity steppers and cart drawer.
- **Toiletries & Amenities Requests** (towels, soap, shampoo, dental kit, pillows, etc.).
- **Custom Staff Request Form** for any special guest needs.
- **Mandatory Checkout Fields**: Room Number, Guest Name, and Extra Notes.
- **Simultaneous WhatsApp & SMS Dispatch** to staff number.
- **Live Track Page** where all guests can see active orders across rooms with **ONLY Room Number and Order Price** displayed for privacy.
- **Kitchen Dashboard** for food & drink preparation.
- **Hotel Staff Dashboard** for front desk & housekeeping.
- **Pre-Acceptance Verification Alert**: *"Check customer is present in the room before accepting the order"*.
- **Supabase Cloud Integration** with Realtime synchronization.
- **Free Vercel Deployment Ready**.

## Quick Start
1. Run `npx serve .` to preview locally or open `index.html` in any browser.
2. For Supabase & Vercel deployment, see [VERCEL_AND_SUPABASE_GUIDE.md](./VERCEL_AND_SUPABASE_GUIDE.md).
